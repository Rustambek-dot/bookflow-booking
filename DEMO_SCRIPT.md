# Demo Script — BookFlow (4 минуты)

1. **Landing** (20с) — «Система онлайн-записи для сервисных бизнесов». Показать hero и pricing.
2. **Виджет /book** (90с) — ключевой момент: пройти все 4 шага (услуга → мастер → слот → контакты → подтверждение). Отметить: «Слоты рассчитаны движком из графика мастера — двойная бронь невозможна даже на уровне БД».
3. **Дашборд** (40с) — записи сегодня, выручка, загрузка недели.
4. **Bookings** (30с) — фильтры по статусу, поиск, no-show/cancelled.
5. **Services CRUD** (30с) — добавить услугу вживую, отредактировать цену.
6. **Analytics** (30с) — utilization по мастерам, no-show rate, revenue.
7. **Settings → Integrations** (20с) — «Stripe, Google Calendar, Resend за адаптерами; сейчас mock mode, реальные ключи подключаются за минуты».
8. **Финал** (10с) — тёмная тема, мобильный вид.
